# War Room Master Control Sheet

## Objective
Show fully autonomous newsroom demo with CI/CD + human-in-loop governance.

## Demo Priority
1. Feed ingestion visible  
2. Breaking detection working  
3. Credibility scoring correct  
4. Article generation functional  
5. Personalization switch works  
6. Human approval panel active  
7. Auto-publish simulation  
8. CI/CD pipeline screen visible  

## Team Commands
- Architect: final authority, orchestrator, prompts  
- Backend: feed, clustering, summarization, personalization  
- Frontend: dashboard, monitoring, testing, demo UX  

## Agent Flow Check
- Feed → Detect → Filtration → Credibility → Article → Personalize → Approval → Publish → CI/CD

## Testing Rules
- Continuous validation embedded  
- Humans intervene only for critical failures  
- Mock data fallback allowed  

## Demo Pitch
> “JioNews Sentinel is an autonomous newsroom that detects breaking news, verifies credibility, generates articles, personalizes content, and auto-publishes. Human oversight only for critical approval. Automated CI/CD ensures continuous safe deployment.”
