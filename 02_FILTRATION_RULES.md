# Filtration & Governance Rules

All news must pass a layered AI filtration pipeline:

1. **Duplicate Removal** — discard repeated headlines/content  
2. **Spam Detection** — identify low-quality sources  
3. **Credibility Threshold** — minimum credibility score before auto-publish  
4. **Source Trust Ranking** — prioritize high-trust news providers  
5. **Risk Scoring** — evaluate fake risk, misinformation potential  
6. **Editorial Policy Filter** — sensitive political, violent, or sensitive content flagged  
7. **Geo/Political Sensitivity Filter** — optional high-risk geographies flagged  

### Execution Principle
- Agents evaluate each layer sequentially  
- Only if all filters passed → allow auto-publish  
- Otherwise → human approval required
