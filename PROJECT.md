```json
// src/config/domains/your-domain.json
{
  "domainId": "video",
  "name": "Video Intelligence Platform",
  "contentType": "video",
  "categories": ["Tutorial", "Entertainment", "Education"],
  "agentPipeline": [...],  // Your agents
  "thresholds": {...}       // Your rules
}
```

```bash
# Deploy instantly
curl -X POST http://localhost:3000/api/domains/video/reload
```

## 🔌 **Generic API Layer**

### Content API (Works for ALL Domains)

```bash
GET  /api/content                              # List content
GET  /api/content/:id                          # Get single item
GET  /api/content/domain/:domain/trending      # Trending
POST /api/content/search                       # Search
PATCH /api/content/:id/approve                 # Approve
```

### Domain API

```bash
GET  /api/domains                              # List domains
GET  /api/domains/:domainId/config             # Get config
GET  /api/domains/:domainId/pipeline           # Get pipeline
POST /api/domains/:domainId/reload             # Hot-reload
```

### Monitoring API

```bash
GET  /api/health                               # System health
GET  /api/orchestrator/health                  # Agent metrics
```

**Total: 32 Endpoints** (17 generic + 15 legacy)
